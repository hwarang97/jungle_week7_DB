B+ Tree Search Simulator

현재 `jiun` 브랜치의 구조체와 `search` 동작을 사람 눈으로 확인하기 위한 설명용 시뮬레이터입니다. 루트에서 시작해서 어떤 자식으로 내려가는지, 리프에서 어떤 key 와 비교하는지를 단계별로 보여줍니다.

현재 테스트에 쓰는 예시 트리

현재 코드의 `search`는 내부 노드의 key 구간을 보고 자식으로 내려간 뒤, 리프 노드 안에서 key 를 다시 비교하는 방식입니다.

root 내부 노드
child[0] left leaf
child[1] middle leaf
child[2] right leaf
root 의 key 구간을 보고 어느 리프로 내려갈지 결정합니다.
left leaf 리프 노드
next → middle leaf
middle leaf 리프 노드
next → right leaf
right leaf 리프 노드
next → NULL

탐색 실험

key 를 넣고 `search` 버튼을 누르면, 현재 구현이 어떤 비교를 하고 어디로 내려가는지 단계별로 보여줍니다.
